# ☕ Java OOP Assignments

Short Java programs practising object-oriented basics: classes, constructors, encapsulation and methods.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## Programs (`DSA - 2/src`)

| File | What it does | Concepts |
|---|---|---|
| `Biggest.java` | Finds the largest element in an integer array | Constructors, arrays, loops |
| `Rectangle.java` | Rectangle with validated setters and an area method | Encapsulation, default & parameterised constructors, getters/setters |
| `MessagePrinter.java` | Prints a personalised greeting | Instance methods |
| `Main.java` | Project entry point | — |

## Run it

```bash
cd "DSA - 2/src"
javac *.java
java Rectangle      # or: java Biggest / java MessagePrinter
```
Or open `DSA - 2` in IntelliJ IDEA.
